# Островок AI v9 — быстрый запуск и проверка

## 1. Установка

Нужен Python 3.11+ (для интерфейса достаточно браузера). Docker для локальной проверки не требуется.

**macOS / Linux:**

```bash
cd ostrovok-ai-v9
sh start.sh
```

**Windows PowerShell:**

```powershell
cd ostrovok-ai-v9
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Скрипты устанавливают зависимости и запускают веб-сервер на локальном адресе `127.0.0.1:8090`. Не используйте настройки локальной демонстрации при публикации на внешнем сервере.

Откройте:

- `http://127.0.0.1:8090` — Telegram Mini App (доступен также в обычном браузере).
- `http://127.0.0.1:8090/operator` — панель проверяющего (для локального демо).
- `http://127.0.0.1:8090/docs` — API Swagger.

## 2. Пример городского события

В отдельном терминале внутри той же папки и виртуального окружения:

```bash
python -m intelligence.city_import data/city_notice_template.csv
python -m intelligence.city_import data/city_notice_template.csv --apply
```

Первый вызов выводит план импорта и ничего не публикует; второй создаёт запись, ожидающую проверки. Обратите внимание: `data/city_notice_template.csv` содержит **полностью вымышленное учебное уведомление**, а не городскую публикацию.

В операторской панели нажмите «Обновить данные», откройте «Городские записи». Проверьте тестовую карточку и нажмите «Одобрить» только в локальной демонстрации. После этого откройте поиск по датам 10–12 ноября 2026 года. Наличие предупреждения зависит от того, есть ли в каталоге отель с подтверждёнными координатами достаточно близко к учебной геоточке. Отсутствие предупреждения без подтверждённой геопозиции ожидаемо.

## 3. Проверка версий

Измените `title`, `starts_on` или `ends_on` учебной записи в своей копии CSV, сохранив `provider` и `source_reference`. Повторите импорт с `--apply`.

Пока новая запись ждёт проверки, старая остаётся опубликованной. После одобрения новой редакции старая меняет статус на `superseded`. Если новую редакцию отклонить — старая сохранится.

## 4. Настоящие источники

Не подключайте случайные URL. Сначала проверьте юридические условия доступа и структуру CSV/JSON. Поддерживается импорт из локального файла и конфигурируемого HTTPS-источника. См. [V9_CITY_SOURCES.md](V9_CITY_SOURCES.md).

## 5. Тесты

```bash
python -m pytest -q
node --check web/app.js
node --check web/operator.js
```

Наличие Node.js требуется только для отдельной проверки синтаксиса JavaScript, не для запуска самого приложения.

## 6. Оставшиеся ограничения

Это самостоятельный Intelligence-модуль и мини-приложение, пока без физического объединения с оригинальным Go-репозиторием. Городской источник Сочи с готовыми геоданными и календарём фактических работ не подтверждён. Полноценные PostgreSQL и внешние live-API должны проверяться в сетевой среде.
