# Единый прототип Mini App + Intelligence

## Быстрый запуск без Docker

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn intelligence.api:app --reload --port 8090
```

- `http://127.0.0.1:8090/` — клиентский интерфейс.
- `http://127.0.0.1:8090/docs` — проверка API.
- `http://127.0.0.1:8090/ready` — состояние хранилища.

В демо создан один объект. Источники из демоснимка и синтетическая геометрия не являются независимой проверкой текущих условий отдыха.

## PostgreSQL/PostGIS

Скопируйте `.env.example` в `.env` и задайте длинные уникальные `POSTGRES_PASSWORD` и `OSTROVOK_API_TOKEN`.

```bash
docker compose up --build -d
```

Mini App будет на `http://127.0.0.1:8090/`. Фактический запуск Docker и миграций необходимо выполнить в среде с Docker.

## Telegram

Для Telegram нужен HTTPS-домен. Для публикации обязательны проверка Telegram `initData`, привязка пользователя к роли и конкретному отелю, ограничение частоты запросов и отключение demo-модификаций. Текущая страница — локальный прототип, **не готовое к публичному размещению приложение**. Telegram WebApp SDK подключён для адаптации интерфейса, но серверная Telegram-аутентификация ещё не реализована.

## Кабинет отельера

Маршруты ответов защищены сервисным токеном. Нельзя передавать этот токен в браузер. Поэтому интерактивная запись из браузера на общем Docker-сервере заблокирована, пока Go BFF не реализует отдельную авторизованную сессию. В локальном SQLite-demo без токена запросы к кабинету разрешаются только с loopback. Создание вопросов и подтверждения можно проверять через защищённый API / Swagger по инструкции `docs/DEMO_WALKTHROUGH.md`.

## Интеграция с Go API

Это единый запускаемый модуль Intelligence + интерфейс, но **не слияние с GitHub репозиторием GrekEv/ostrovok**: полный исходный Git-репозиторий в среде недоступен. Go-адаптер находится в `examples/go-bff`; его необходимо встроить в реальные Go-роуты после получения исходников. `travel_cards` и `user_swipes` оригинального проекта пока не подключены.
